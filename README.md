# mock-data-names

A minimal Python script for working with [`MOCK_DATA.csv`](MOCK_DATA.csv), a 1000-row synthetic dataset (`id, first_name, last_name, email, gender, ip_address`) generated by [Mockaroo](https://mockaroo.com/).

## Usage

```bash
python3 show_names.py
```

Prints each row's `first_name` and `last_name`. Use a different file with `--csv`:

```bash
python3 show_names.py --csv path/to/other.csv
```

No third-party dependencies — everything used is in the Python standard library.

## Tests

```bash
python3 -m unittest discover
```
